# R15 — native near-pane acquisition

Q75 reports complete failure to grab/move the pane on Quest. At fixed `fa567a2`, installed Three's `WebXRController.update` with synthetic index/thumb poses exposes two separate gaps: joint-derived `pinchstart` is not consumed as a manipulation signal, and a finite fingertip overlapping the actual edge is rejected when its centre is just outside or behind the pane. Neither establishes which path occurred on the user's headset.

The pane alone opts into joint-derived near pinch. Semantic WebXR select remains separate and continues to support controller/far actions. Either live signal can sustain an acquired pane; ending one cannot release the other or create duplicate ownership. Native-only acquisition requires visible index and thumb joints; loss/reset requires opening before reacquisition. It does not create native far clicks, row selections, or a scene-wide pinch policy.

Edge acquisition accepts finite fingertip overlap with the actual deformed mesh, whose closest point must lie in the existing Q71 left/right lane. A cached XY triangle index bounds the contact query; the mesh still follows the same Z-only bend. This covers rim/back overlap during a straddled grasp without extending the lane into the title/body or a disconnected rear surface. The same predicate is used by routing and WindowControls, and the dent anchor is the actual surface point. Rest geometry, corner resize, existing ownership and sphere Glow remain unchanged.

The native rig uses installed Three and real InputSystem/PackagingPanel with synthetic two-tip poses; it is not device evidence or a full-hand palm model. Original v1/v2 failures and fixture corrections are preserved in the companion R15 revision-01. The first candidate run mislabeled a back-overlap pose as a straddle; the corrected test asserts opposite-side joint positions and adds stationary world-space hand stability. Existing fixed-SHA screen/review and Quest checks remain necessary. Q78's list opacity values are pending and are not selected by this independent change.
